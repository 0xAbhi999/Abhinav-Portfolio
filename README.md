# Abhinav Deshmukh Portfolio

Personal portfolio built with React, TypeScript, Vite, and Lucide icons.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Personalize

- Add the supplied binary background image at `public/binary-bg.png`.
- Add a resume PDF at `public/resume.pdf` for the hero download link.
- Replace the GitHub and LinkedIn placeholders in `src/data/portfolio.ts`.
- Replace each project repository placeholder in the same data file.

The contact form validates fields in the browser but has no backend; submitting it does not transmit a message.
